# Text Analyzer

A simple command-line text analyzer written in Python.

## Features

- Converts text to lowercase
- Removes basic punctuation
- Counts total words
- Counts unique words
- Counts characters excluding spaces
- Finds the longest word or words
- Calculates word frequencies
- Finds the most frequent word or words
- Rejects empty input

## Concepts Practiced

- Functions
- Dictionaries
- Sets
- Loops
- String processing
- Input validation
- Tuple unpacking
- Basic text normalization
