# Mini Poll Analyzer

A simple command-line poll analyzer written in Python.

## Features

- Collects user choices until `bitir` is entered
- Rejects empty input
- Normalizes user input
- Counts total votes
- Counts unique choices
- Calculates choice frequencies
- Finds the most selected choice or choices
- Handles ties

## Concepts Practiced

- Functions
- Lists
- Dictionaries
- `while` loops
- Input validation
- Frequency counting
- Tuple unpacking
- Basic string normalization
