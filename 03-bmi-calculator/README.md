# BMI Calculator

A simple BMI calculator built with Python and Tkinter.

## Features

- Calculates BMI from weight and height
- Accepts height in centimeters or meters
- Classifies the calculated BMI
- Handles empty, invalid, zero, and negative inputs
- Simple graphical interface built with Tkinter

## Structure

- `bmi_calculator.py` — BMI calculation and classification logic
- `ui.py` — Tkinter interface, input validation, and unit conversion
